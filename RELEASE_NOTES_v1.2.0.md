# SJ Hotkeys v1.2.0

SJ Hotkeys v1.2.0 adds a standard Windows installation option and several usability improvements.

## What's new

- Install per user with the new Setup package. It needs no administrator rights, includes the .NET runtime, adds SJ Hotkeys to the Start menu, and provides a normal Windows uninstall entry.
- Export and import all program paths and keyboard shortcuts as a local `.sjhotkeys` profile.
- Drag `.exe` files and `.lnk` shortcuts into the app to create a hotkey; the shortcut dialog opens with the program selected.
- Updated custom title bar, settings icon, and larger full-width **Add Hotkey** action.
- Improved startup registration so an enabled Windows startup entry is restored after reinstalling the app.
- The README now contains the SJ Studios logo without application screenshots.

## Downloads

- **Setup** — recommended for most users; installs SJ Hotkeys for the current Windows user and includes the .NET runtime.
- **Portable** — self-contained executable; no installation or separately installed .NET runtime required.
- **Lightweight** — smaller executable; requires the .NET 9 Desktop Runtime (x64).

All downloads are for Windows x64. `SHA256SUMS.txt` contains checksums for verifying each release file.
