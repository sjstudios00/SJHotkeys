# Icon sources

The following CC0 icons from SVG Repo are used for the title-bar controls:

- Settings cog: https://www.svgrepo.com/svg/389791/settings-cog-gear
- Close: https://www.svgrepo.com/svg/499592/close-x
- Minimize line: https://www.svgrepo.com/svg/110692/horizontal-line

The vectors are recolored at runtime to match the app's theme.
